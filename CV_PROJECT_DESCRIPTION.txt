ElephantGuard AI — Human-Elephant Conflict Prevention System
Smart India Hackathon 2025 | Team Glitch Hunters_1 (ID: 98915) | PS-25167
GitHub: github.com/GlitchHunters1/elephant-guard-ai

Developed an AI + IoT-powered real-time elephant detection and early warning
system to prevent Human-Elephant Conflict (HEC) in forest-border communities
across India, where ~595 human deaths and 45+ elephant deaths have been
recorded in the past decade.

Key Contributions:
• Built a real-time object detection pipeline using YOLOv7 and OpenCV,
  trained on 4,200+ thermal elephant images, achieving ~91.4% mAP@0.5
• Implemented on-device inference using TensorFlow Lite (INT8 quantised)
  on ESP32 and Raspberry Pi, enabling fully offline edge AI operation
• Designed multi-sensor fusion system combining PIR sensors, 24 GHz
  Doppler radar, and MLX90640 thermal camera for robust detection
• Built end-to-end IoT pipeline: ESP32 sensor nodes → LoRa radio (10–15 km
  range) → Raspberry Pi gateway → MQTT → FastAPI → TimescaleDB
• Integrated multi-channel alert system (siren, LED strobe, SMS via Twilio,
  WhatsApp API) with <5 second end-to-end latency from detection to alert
• Developed live monitoring dashboard using Node-RED and FastAPI showing
  real-time events, node health, and detection confidence scores
• Implemented solar + battery power system for continuous off-grid operation
  in remote forest environments; IP65 weatherproof enclosures for deployment

Tech Stack: Python, C/C++, YOLOv7, OpenCV, TensorFlow Lite, ESP32,
Raspberry Pi, LoRa/LoRaWAN, MQTT, FastAPI, PostgreSQL/TimescaleDB,
Node-RED, Twilio API, PlatformIO, Git
